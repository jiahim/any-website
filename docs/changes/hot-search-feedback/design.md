# 热门搜索与生成页面评价

状态：用户已确认实施；不使用 Linear。不包含提交、PR、部署或生产迁移。

## 决策
- 首页分为“网站热词”和“社会热词”两个独立区域，替换原排行榜。网站热词仅使用本站真实探索与评价；社会热词仅使用百度中文热榜。各最多 12 条，独立请求、排序、刷新和空态，互不补位；允许同一词分别出现在两类中。标明来源，去掉虚拟次数。
- 站内统计所有保留的真实历史，不以时间截断；每个 path/userHash 只取最近探索，贡献 2^(-ageDays/30)。先过滤占位、无效、乱码和软删除词，再排序。规范 Unicode、空白和路径编码；仅合并精确规范化重复，保留不同语义路径。
- 质量修正：每个匿名访客对路径下有效实例评价取平均，每位访客最多贡献一个正/负票单位。采用 Beta(5,5) 平滑，乘数 0.8 + 0.4 × (正票+5)/(正票+负票+10)。无评价为 1，单票影响很小；汇总所有保留的有效生成实例，不按 30 天截断。取消存为 0，不计票；切换覆盖，不累加。
- 外部源读取百度公开页面结构化榜单，无 API Key；30 分钟缓存、24 小时硬过期；持久 DB 快照 + 进程内后备；固定来源、超时、响应大小上限及并发请求合并。返回抓取时间，不声称是上游发布时间。
- 服务端仅在 SSE 正常结束且包含完整 HTML 时记录 GeneratedPage，绑定 HttpOnly 匿名访客 cookie；客户端不能自行注册实例。评价 GET/PUT 验证实例归属，PUT 为绝对状态 -1/0/1，事务外无累计计数。
- 完成实例 ID 经尾部 SSE 元数据传给客户端。当前标签页 sessionStorage 保存最近实例 HTML（上限 1MB、30 分钟），刷新恢复同实例；超期/存储失败重新生成，评价不继承。服务端不保存 HTML。
- 评分、ID、状态、过滤、时效全部由确定性代码管理，不增加 AI 调用。

## 风险与回滚
- 匿名 cookie 不是账号认证，清 cookie 可重新评价；不宣称强防刷。既有 IP+UA 去重也只是访客估计。
- 百度页面结构和部署地区可能影响抓取。过期内容隐藏；数据库不可用时外部热词仍可工作，评价明确不可用，生成不能因此失败。
- 取消 UserSearchLog 的 30 天清理；含原始 IP/UA 的 SearchRecord 仍保留 90 天。已被旧任务删除的历史无法凭累计计数还原。新增查询索引；不删改线上历史 seed 数据。
- 增量表无破坏性字段修改；回滚应用后可保留新表。上线前必须应用增量 SQL，验证生产网络及数据库迁移。
